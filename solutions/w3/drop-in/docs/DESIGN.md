สัญญากลางของ Workshop 4 ขั้น Implement และขั้น Review ต้องยึดไฟล์นี้

## ผลลัพธ์

สคริปต์ SQL `scripts/clean-export.sql` อ่าน `data/raw/dbd-2558.parquet` ด้วย DuckDB แล้ว `COPY` ออกมาเป็น `data/dataset.csv` ที่ `npm run gate` เคส `data-quality` ผ่าน (0 violations)

## แถวที่ทิ้ง (fatal)

- แถวที่ `seq_raw` ไม่ใช่จำนวนเต็มได้ — คือหัวตาราง ชื่อไฟล์ และคำว่า "ทั่วประเทศ" ที่ปนมาจากการรวมรายเดือน (9 แถว)
- `reg_no` ไม่ตรง `^[0-9]{13}$`
- ชื่อนิติบุคคลหรือวัตถุประสงค์ว่าง
- `capital_raw` แปลงเป็นตัวเลขไม่ได้
- วันที่ไม่ตรง `%d/%m/%Y` (ต้นฉบับเป็น พ.ศ. ทุกแถว — แปลงแล้วจึงไม่มีใครโดนทิ้งจากเงื่อนไขนี้)

## แถวที่ซ่อม (repairs)

- `seq`: ตัดลูกน้ำออก (`1,000` → `1000`) แล้ว CAST เป็น BIGINT
- `reg_date`: `strptime('%d/%m/%Y')` ลบ 543 ปี แล้ว `strftime` เป็น ISO `YYYY-MM-DD` (`12/1/2558` → `2015-01-12`)
- `capital`: ตัดลูกน้ำและช่องว่าง (`" 2,000,000,000 "` → `2000000000.00`)
- `province`: ดึงจากที่อยู่ด้วยกฎ "ชื่อจังหวัดที่ปรากฏใกล้ท้ายที่อยู่ที่สุดชนะ" — เพราะมีที่อยู่พูดถึงจังหวัดอื่นกลางประโยค (เช่น ถนนบางนา-ตราด ซึ่งอยู่ในกรุงเทพฯ) ใช้ `strpos` + `row_number()` เรียงตำแหน่งมากไปน้อย
