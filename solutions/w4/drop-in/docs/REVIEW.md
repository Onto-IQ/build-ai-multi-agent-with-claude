# Review — clean-sales.js

ตรวจเทียบ `scripts/clean-sales.js` กับ `docs/DESIGN.md`

- แถวที่วันที่ ปริมาณ ราคา ส่วนลด จังหวัด หรือช่องทางอ่านไม่ได้ถูก `continue` ทิ้งในฟังก์ชัน `clean` สอดคล้องรายการ fatal ใน DESIGN.md

- วันที่ พ.ศ. ราคาที่มีจุลภาค และชื่อช่องทางคนละตัวพิมพ์ถูกเขียนใหม่ก่อนลงไฟล์ สอดคล้องรายการ repair
- ภาคถูกเขียนจากตารางจังหวัด ไม่ได้เชื่อค่า `region` เดิม เมื่อจังหวัดเป็นเชียงใหม่แต่ภาคในไฟล์ดิบเป็นใต้ แถวที่เก็บได้ต้องเป็นภาคเหนือ
- สคริปต์ไม่ได้แก้ `server.js` ตามขอบเขตใน DESIGN.md ที่กันงานเซิร์ฟเวอร์ไว้ที่ Workshop 5
