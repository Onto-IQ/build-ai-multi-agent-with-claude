# Workshop 8 — Feature ของคุณ: เกณฑ์กำกับ

คุณเลือก feature เอง แต่ต้องผ่านเกณฑ์ทุกข้อ มิฉะนั้นถือว่ายังไม่จบ

## เกณฑ์ (ตรวจทุกข้อก่อนเรียกว่าเสร็จ)

1. **Deploy ได้จริง** — feature อยู่ใน build ที่ขึ้น Vercel (Module 13) และเปิดได้จาก URL จริง
2. **Quality gate ยังเขียว** — `node scripts/quality-gate.js` ยัง exit 0 หลัง feature เข้าโค้ด
3. **ใช้ agents อย่างน้อย 2 ตัว แบบมี handoff** — ตัวหนึ่งวางแผน/วิเคราะห์เป็นไฟล์ อีกตัวทำตามไฟล์นั้น (ห้ามคุยกันในแชทล้วน)
4. **ไม่แตะของต้องห้าม** — ห้ามพิมพ์ค่าที่ขึ้นต้นด้วย `sk-` ห้ามแก้ `scripts/quality-gate.js` และห้ามเพิ่ม dependency (Node ล้วน)

## ไอเดียตัวอย่าง (ดูเป็นแนวทาง ไม่บังคับ)

- ตารางยอดรายจังหวัด ใต้ตารางช่องทางที่มีอยู่
- หน้าเพิ่มออเดอร์ (ฟอร์มสั้น ๆ ที่ POST เข้า API แล้วตารางรีเฟรช)
- ปุ่ม export สรุปยอดเป็น CSV
- การ์ด "พอร์ตที่ขายดีที่สุด" แยกตามภาค

## ขั้นตอนต่ำสุด (handoff ต้องเห็นชัด)

1. สั่ง planner เขียนแผน feature ลง `docs/FEATURE-PLAN.md`
2. สั่ง developer ทำตาม `docs/FEATURE-PLAN.md`
3. สั่ง qa ตรวจว่า gate ยังเขียวและหน้าเว็บทำงานจริง แล้วสรุปผลกลับมา
