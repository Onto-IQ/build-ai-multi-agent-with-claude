# Workshop 8 — Feature ของคุณ

แล็บนี้ไม่มีคำตอบตายตัว — feature เป็นของผู้เรียน

- เกณฑ์อยู่ที่ `FEATURE-CRITERIA.md` (ตรวจด้วย `node solutions/w8/check.js`)
- ขั้นต่ำของ handoff: `docs/FEATURE-PLAN.md` (planner) -> โค้ด (developer) -> ผลตรวจ (qa)
- หลักฐานที่ต้องมีตอนจบ: gate ยัง exit 0, feature อยู่ใน build ที่ deploy, และแต่ละ agent ทิ้งไฟล์ไว้ให้ตัวถัดไปอ่าน
