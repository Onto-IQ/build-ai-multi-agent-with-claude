# PRODUCT-SPEC — Registry Insight dashboard (release v2)

สัญญากลางของทีม Capstone ทุกบทบาทยึดไฟล์นี้ หน้าเดียวที่ `/` ต้องทำให้คนดูเห็นคุณค่าของข้อมูลจริง 16,772 กิจการภายใน 5 วินาที ใช้ได้บนจอโทรศัพท์

## เกณฑ์คงที่ (ห้ามละเมิด)

- Node `http` ล้วน ไม่เพิ่ม dependency ไม่ใช้ไลบรารีกราฟ ไม่ใช้รูปภาพ — กราฟทำด้วย inline SVG เท่านั้น
- contract เดิมคงไว้เป๊ะ:
  - `GET /api/health` → `200` `{ "ok": true }` ห้ามมีฟิลด์หรือสตริงที่ขึ้นต้นด้วย `sk-`
  - `GET /api/summary` → `200` `{ "companyCount": 16772, "totalCapital": 45341868784, "source": "registry-insight" }`
  - `POST /api/notes` บอดี้ที่ไม่ใช่ JSON ได้ `400` และโปรเซสต้องไม่ตาย · `GET /api/notes` คืนรายการ
  - `GET /api/provinces` (feature Workshop 8) คงรูปเดิม
- ทุกตัวเลขบนหน้าเว็บมาจาก API เท่านั้น ห้าม hard-code ยอดใน HTML/JS
- แสดงข้อความผู้ใช้ (โน้ต) ด้วย `textContent` ห้าม `innerHTML`
- quality gate ต้องยัง 6/6 · ห้ามแก้ `scripts/quality-gate.js`

## โครงหน้า `/` (บนลงล่าง)

1. **หัวเรื่อง** — eyebrow แหล่งข้อมูล (data.go.th · DBD 2558) + ชื่อแดชบอร์ด + ประโยคเดียวบอกว่าคืออะไร
2. **การ์ด KPI 4 ใบ** — จำนวนกิจการ · ทุนจดทะเบียนรวม · จังหวัดที่ทุนสูงสุด (พร้อมสัดส่วน) · ภาคที่ทุนสูงสุด (พร้อมสัดส่วน)
3. **ทุนจดทะเบียนรายเดือน** — กราฟแท่ง SVG จาก endpoint ใหม่ `GET /api/monthly` แต่ละแท่งมีป้ายเดือน + ยอดบาท + จำนวนกิจการ
4. **ทุนรายภาค** — แท่งแนวนอน 6 ภาคเรียงมากไปน้อย พร้อม % ของทุนรวม
5. **ตารางจังหวัดทุนสูงสุด** (feature Workshop 8 — ต้องรอดถึง release) — top 10 + แถบสัดส่วน + ภาคกำกับ
6. **บันทึกของทีม** — ฟอร์มส่ง `POST /api/notes` (ข้อความ ≤ 200 ตัวอักษร) + รายการโน้ตที่อ่านจาก `GET /api/notes` พร้อมสถานะว่าง/โหลด/ผิดพลาด
7. **ท้ายหน้า** — แหล่งข้อมูล + สรุปสถานะ release หนึ่งบรรทัด

## การโต้ตอบของผู้ใช้ (client-side จากข้อมูลที่ fetch แล้ว ห้ามเพิ่ม endpoint)

1. **ค้นหาจังหวัด** — ช่องค้นหาเหนือตารางจังหวัด พิมพ์ชื่อแล้วตารางกรองทันที (ไม่สนตัวพิมพ์เล็ก-ใหญ่ ไม่สนสระ/ิ-ี-ึ) แสดง "พบ N จังหวัด" และข้อความสถานะว่างเมื่อไม่เจอ
2. **จัดเรียงคอลัมน์** — คลิกหัวคอลัมน์ (จังหวัด ภาค กิจการ ทุน สัดส่วน) สลับ น้อย→มาก / มาก→น้อย มีลูกศรกำกับและ `aria-sort` บน `<th>`
3. **จำนวนแถว** — ปุ่มเลือก 10 / 20 / ทั้งหมด เปลี่ยนจำนวนแถวในตารางทันที
4. **สลับชนิดกราฟรายเดือน** — ปุ่ม แท่ง / เส้น สลับ SVG ให้ข้อมูลชุดเดียวกัน และวาดใหม่ตอน resize ตามเดิม

ข้อบังคับ: ทุกการโต้ตอบทำงานจากข้อมูลที่ fetch มาแล้วเท่านั้น (ไม่ยิง API ซ้ำ) · ค้นหา + จัดเรียง + จำนวนแถว ทำงานร่วมกันได้ · คง keyboard accessible

## endpoint ใหม่ที่อนุญาต

- `GET /api/monthly` → `{ "months": [ { "month": "jan", "companyCount": 5980, "totalCapital": 18620752814 }, ... ] }` เรียงตามปฏิทิน (ม.ค. → มิ.ย.) คำนวณจากแถว valid เท่านั้น

## ข้อมูล

ใช้ `data/dataset.csv` ที่ผ่าน quality gate แล้วเท่านั้น (16,772 กิจการ / ทุนรวม 45,341,868,784 บาท)

## เกณฑ์ตรวจรับ

1. `npm run gate` ยัง 6/6 exit 0
2. เปิด `/` แล้วเห็นครบทั้ง 7 ส่วน ตัวเลขตรงกับ API ทุกหลัก (เทียบ `/api/summary` กับ KPI, `/api/monthly` กับกราฟ, `docs/region-capital.csv` กับแท่งภาค)
3. ยอดรวมรายเดือน = ยอดรวมรายจังหวัด = ยอดรวมรายภาค = 16,772 / 45,341,868,784
4. โพสต์โน้ตผ่านหน้าเว็บได้ และรอดข้าม restart
5. จอกว้าง ≤ 640px อ่านได้ ไม่มีแถวไส้ขวา
6. ไม่มี dependency ใหม่
7. ค้นหา จัดเรียง เลือกจำนวนแถว และสลับชนิดกราฟ ทำงานจริงและร่วมกันได้ โดยยอดสรุปคงเท่าเดิม
8. มี `docs/EXECUTIVE-SUMMARY.md` ที่ยอดรวมตรงกับ API
