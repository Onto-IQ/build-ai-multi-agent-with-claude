# สรุปผู้บริหาร — ธุรกิจจดทะเบียนใหม่ พ.ศ. 2558

ใช้ได้หลังทำความสะอาด `data/dataset.csv` แล้วเท่านั้น ไฟล์ดิบจาก data.go.th มี 16,781 แถว เก็บได้ **16,772 กิจการ** ทิ้ง 9 แถว (แถวหัวตารางและชื่อไฟล์ที่ปนมาจากการรวมรายเดือน)

## ภาพรวมทุนจดทะเบียน

ทุนจดทะเบียนรวม **45,341,868,784** บาท จาก 16,772 กิจการ ภาคที่ทุนสูงสุดคือ **กลาง** (31,680,888,983 บาท — ราวสองในสามของประเทศ) ตามด้วยตะวันออก 4,171,833,600 บาท

## จังหวัดและภาค

จังหวัดที่ทุนสูงสุดคือ **กรุงเทพมหานคร** (23,529,709,183 บาท) ตามด้วยชลบุรี 2,970,555,600 บาท และสมุทรปราการ 2,779,170,000 บาท อีสานและเหนือมีจำนวนกิจการใกล้เคียงกันที่ 1,480 กิจการ แต่ทุนต่อกิจการของเหนือสูงกว่าเล็กน้อย

## คุณภาพข้อมูล

ก่อนทำความสะอาด `npm run gate` รายงานแดง 0/6 — ไฟล์ดิบมีแถวหัวตารางปน วันที่แบบ พ.ศ. (`12/1/2558`) ทุนแบบ `" 2,000,000,000 "` และจังหวัดฝังในที่อยู่ ทำความสะอาดด้วย DuckDB (Workshop 3) จึงจะได้ตัวเลขชุดนี้ ห้ามใช้ยอดจากตัวอ่านชุดเริ่มต้น เพราะตัวเลขนั้นนับคนละชุดกับแถวที่ผ่านกฎ

## ข้อเสนอแนะ

1. ยกระดับทุนต่อกิจการในต่างจังหวัด — กลางกินส่วนแบบ 2 ใน 3 ของทุนรวม
2. มาตรฐานข้อมูลควรล็อกวันที่เป็น `YYYY-MM-DD` และทุนเป็นตัวเลขตั้งแต่ต้นทาง
3. เปิดแดชบอร์ดชุดนี้หลัง `npm run gate` จบด้วย exit 0 ทุกครั้ง
