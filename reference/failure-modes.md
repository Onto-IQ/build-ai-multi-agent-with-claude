# Failure modes

อาการที่เจอซ้ำเมื่อสั่งทีมเอเจนต์ กันที่ขั้นตอน ไม่กันด้วยการขอร้องในประโยคเดียว

| อาการ | กันด้วย |
|---|---|
| บอกว่าเขียนไฟล์แล้ว แต่ไฟล์ไม่มี | เปิดไฟล์หรือรัน `node scripts/quality-gate.js` ทุกครั้ง |
| ทีมขนานแล้วไปคนละทิศ | เขียนสัญญากลางก่อนแตกงาน |
| รายงานยาวจนบทสนทนาหลักจม | จำกัดความยาวหรือรูปแบบใน prompt |
| หมดเทิร์นก่อนลงมือ | อย่าตั้ง `--max-turns` ต่ำเกิน และอย่าสั่งให้สำรวจยาวในรอบที่ต้องเขียนไฟล์ |
| เขียน `.claude/**` ไม่ได้ใน `claude -p` | ทำแล็บใน TUI แล้วกดอนุญาต |
| Bash ถูกปฏิเสธใน `claude -p` | ใส่ธงที่แล็บระบุ หรือกลับไปใช้ TUI |
| `ANTHROPIC_API_KEY` ทับบัญชีคลาส | `unset ANTHROPIC_API_KEY` ก่อนเปิด `claude` |
| ฆ่า Node ทั้งเครื่อง | ปิดเฉพาะ PID ของพอร์ต อย่าใช้ `taskkill //IM node.exe` |
| port 3000 busy (port busy) | ปิดเซิร์ฟเวอร์เก่า หรือตั้ง `PORT` |
| แก้ตัวตรวจแทนของที่ถูกตรวจ | ห้ามแก้ `scripts/quality-gate.js` เพื่อให้เขียว อ่าน diff ก่อนรับงาน |
