# Workshop 1 — Parallel Codebase Exploration (Swarm)

## บริบท

คุณเพิ่งเข้ารับโปรเจกต์ `labs-sandbox/demo-shop` (เว็บร้านค้า Node.js ขนาดเล็ก) ที่ไม่มีเอกสารเลย คุณมีเวลา 10 นาทีต้องบรีฟทีม — จึงใช้ทีม Subagent สำรวจพร้อมกันแทนการอ่านเอง

## โจทย์

เขียน **Prompt เดียว** สั่ง Leader ให้ dispatch Subagent ขนาน 3 ตัว สำรวจโครงการ แล้วรวมรายงาน

## ขั้นเริ่มต้น

```bash
cd labs-sandbox/demo-shop
claude
```

## เกณฑ์ผ่าน (ตรวจได้จริง)

- [ ] ใช้ prompt เดียว (ไม่ได้ถามทีละคำถาม 3 รอบ)
- [ ] รายงานที่ได้ครบ 3 หมวด: โครงสร้างโปรเจกต์ / endpoints / จุดน่าสงสัย
- [ ] ระบุ endpoint ครบอย่างน้อย 4 ตัว และมี HTTP method กำกับ
- [ ] ไม่มีไฟล์ใดถูกแก้ไข (`git status` ต้อง clean)
- [ ] รายงานไม่เกิน ~300 คำ (ฝึกคุม output ให้กระชับ)

## Hint (กดเมื่อติด 15 นาที)

เริ่ม prompt ด้วย "Dispatch 3 parallel Explore subagents..." แล้วไล่ task เป็นเลข 1-2-3 — ปิดท้ายด้วยรูปแบบผลลัพธ์และข้อห้ามแก้ไฟล์

## Solution (ตัวอย่างที่ผ่านเกณฑ์)

ดู prompt เต็มใน `lesson.md` หัวข้อ 3 (✅ tested **ทั้ง EN (run-002) และ TH (run-008)**) — ส่วนที่คนพลาดบ่อยคือลืมกำหนดความยาวรายงาน ทำให้ Leader ตอบยาว 2 พันคำ

**เวอร์ชันไทย (✅ tested — run-008):** โครงเดียวกัน — "จง dispatch Explore subagent แบบขนานกัน 3 ตัว..." ปิดท้ายด้วย "ส่งรายงานรวมเป็นชุดเดียวไม่เกิน 300 คำ" และ "ห้ามแก้ไขไฟล์ใด ๆ" — ผลจริง: รายงานไทยทั้งชุด พร้อม severity HIGH/MEDIUM/LOW ที่ agent จัดให้เอง

## ต่อยอด (โจทย์ปลายเปิด)

เปลี่ยน task ที่ 3 เป็นการวิเคราะห์ "ถ้าจะเพิ่มระบบสั่งซื้อ ต้องแก้ไฟล์ไหนบ้าง" แล้วเทียบว่ารายงานเปลี่ยนไปอย่างไร
