    :: Chatbot
    :: ตอบคำถามแล้วจบ ¶ ไม่มีอะไรเปลี่ยนในโลกจริง ¶ ให้คำตอบเป็นข้อความ ¶ ผู้ใช้ต้อง copy ไปทำต่อเอง
    :: AI Agent
    :: วงจร Agentic Loop ¶ รับโจทย์ → วางแผน → เลือกเครื่องมือ → ลงมือ → ตรวจผล → ส่งมอบ ¶ Tool Calling ¶ เรียกรันเครื่องมือเอง แล้วอ่านผลจริงกลับเข้า context

[15] Swarm หรือ Sequential? ดูว่างานขึ้นต่อกันไหม
    :: สถานการณ์
    :: เลือก
    :: เหตุผล
    :: สำรวจ server.js + sales.csv + quality gate
    :: Swarm ขนาน
    :: อ่านคนละไฟล์ ผลไม่ขึ้นต่อกัน
    :: ออกแบบตัวทำความสะอาด → เขียน → รีวิว
    :: Sequential
    :: ขั้นหลังต้องเปิดไฟล์ของขั้นก่อน
    :: หน้าเว็บ + API หลังมี PRODUCT-SPEC
    :: Swarm (หลังมีสัญญากลาง)
    :: สัญญาชัด = ขนานได้ปลอดภัย
    :: แก้บั๊กจุดเดียว ต้องไล่สถานะต่อเนื่อง
    :: อย่าตั้งทีม
    :: Multi-agent บวมโดยไม่จำเป็น
    :: Subagent ที่ขนานกันโดยไม่มี “สัญญากลาง” (spec/contract) จะตัดสินใจขัดแย้งกันเอง เช่น ตั้งชื่อ API คนละแบบ
