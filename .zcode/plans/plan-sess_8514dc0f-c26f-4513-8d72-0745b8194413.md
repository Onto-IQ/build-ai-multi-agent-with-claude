# จัดลำดับหัวข้อฝึกอบรมใหม่เชิงการสอน

แก้ไขไฟล์ `vibe-code-l2-course-outline-rev1.md` โดยคงเนื้อหาทุกหัวข้อเดิม ปรับเฉพาะ**ลำดับและการจัดกลุ่มช่วงเวลา**ให้เป็นเส้นทางการเรียนรู้ที่ต่อเนื่อง

## ลำดับใหม่ที่เสนอ

**วันที่ 1 — เช้า: รู้จัก Agent และสร้างผู้ช่วยตัวแรก**
1. AI Agent ทำงานเป็นทีมได้ยังไง *(คงเดิม)*
2. Technical Environment Setup *(คงเดิม)*
3. Claude Code Specialist Agent + Workshop Code Researcher Agent *(คงเดิม — ปิดท้ายช่วงเช้าด้วย Workshop)*

**วันที่ 1 — บ่าย: เสริมพลังและควบคุม Agent**
4. สอนสร้าง Skills ใน Claude *(ย้ายจากเช้า → บ่าย)*
5. MCP คืออะไร *(ย้ายจากเช้า → บ่าย)*
6. Persistent Memory *(คงเนื้อหา ปรับลำดับขึ้นก่อน)*
7. Permission Boundary *(สลับมาอยู่ท้ายสุดของวันที่ 1 — เชื่อมธีมความปลอดภัยเข้ากับ Governance ของวันที่ 2)*

**วันที่ 2 — เช้า: จาก Solo Builder สู่ทีม Agent**
8. Vibe Coding with Sub-Agent *(ย้ายจากบ่ายวันที่ 1 → เปิดเช้าวันที่ 2 — นิยามบทบาททีม Frontend/Backend/QA/Competitive ที่ Workshop ถัดไปใช้)*
9. Multi-Agent on Claude Code + Workshop ทีม AI 3 ตัว Sequential Workflow *(คงเดิม แต่ Workshop จะมีบทบาทจากข้อ 8 รองรับแล้ว)*

**วันที่ 2 — บ่าย: ควบคุม รวมผล และส่งมอบ**
10. The "Gate" Pattern & AI Guardrails *(คงเดิม)*
11. The "Synthesize" Pattern *(คงเดิม)*
12. Deploy to Vercel *(คงเดิม — ปิดคอร์สด้วยการส่งมอบงานจริง)*

## เหตุผลหลักของลำดับใหม่
- **Skills/MCP ไปบ่ายวันที่ 1:** เช้าวันที่ 1 จบที่ Workshop สร้าง Agent ตัวแรกพอดี ส่วนบ่ายเป็นชุด "เสริมความสามารถ" (Skills → MCP → Memory) แล้วปิดด้วย "ควบคุม" (Permission) — ภาระเช้าวันที่ 1 ไม่หนักเกินไป
- **Memory ก่อน Permission:** จัดกลุ่มหัวข้อความสามารถ (Skills, MCP, Memory) ต่อเนื่องกัน แล้วจบวันด้วยธีมการกำกับดูแล ซึ่งต่อยอดสู่ Gate Pattern วันที่ 2
- **Vibe Coding with Sub-Agent เปิดวันที่ 2:** ชื่อเดิมของหัวข้อนี้คือ "From Solo Builder to Multi-Agent System" จึงเป็นสะพานเข้าสู่วันที่ 2 พอดี และบทบาททีม (Frontend/Backend/QA/Competitive) ที่นิยามไว้ในหัวข้อนี้ คือสิ่งที่ Workshop ทีม AI 3 ตัว (ข้อ 9) ใช้ทันที — ปัญหาเดิมคือ Workshop มาก่อนนิยามบทบาท
- **Dependency ทุก Workshop เรียงถูกต้อง:** Workshop ข้อ 3 (ต้องมี setup ข้อ 2) → Workshop ข้อ 9 (ใช้บทบาทจากข้อ 8) → Workshop ข้อ 10 (กำกับทีมจากข้อ 9) → Workshop ข้อ 11 (รวมโค้ดจากทีม) → ข้อ 12 Deploy (ส่งมอบแอปจากข้อ 11)

## สิ่งที่จะแก้ไขในไฟล์
1. **หัวข้อ 6 (หัวข้อฝึกอบรม):** จัดตำแหน่งหัวข้อตามตารางด้านบน เพิ่มชื่อธีมกำกับแต่ละช่วง (เช่น "รู้จัก Agent และสร้างผู้ช่วยตัวแรก") และปรับหมายเหตุกำกับท้ายหัวข้อที่อ้างอิงตำแหน่งเดิมให้ชัดว่าอิงไฟล์ทาน
2. **หัวข้อ 7 (สรุปรายการ Workshop):** อัปเดตคอลัมน์ "อยู่ในหัวข้อ" ให้ตรงกับช่วงเวลาใหม่
3. **ภาคผนวก ง (บันทึกการปรับปรุง):** เพิ่มรายการวันที่ 29 ก.ย. — จัดลำดับหัวข้อใหม่เชิงการสอน พร้อมเหตุผลโดยย่อ
4. ตรวจทานว่าการอ้างอิงเลขหัวข้อทั้งหมดในเอกสารสอดคล้องกับลำดับใหม่
