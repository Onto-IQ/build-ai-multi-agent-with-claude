# [DRAFT] Pre-class Email / FAQ — สิ่งที่ต้องเตรียมก่อนวันอบรม

> **สถานะ: ร่าง** — รอเจ้าของหลักสูตรรีวิวก่อนใช้จริง | สร้างจากรายงานวิจัย `research-2026-10-09-one-claude-impact.md` (checklist ข้อ 8)

## ต้องติดตั้งอะไรบ้าง

ต้องมีแค่ 2 อย่าง:

1. **Node.js ≥ 20 (Latest LTS)** — ดาวน์โหลดจาก nodejs.org แล้วติดตั้งให้เรียบร้อยก่อนวันอบรม
2. **Claude Code CLI (เวอร์ชัน ≥ 2.1.296)** — ติดตั้งด้วยคำสั่งเดียว:

```bash
npm install -g @anthropic-ai/claude-code
```

ตรวจเวอร์ชันหลังติดตั้งด้วย `claude --version` — ถ้าต่ำกว่า 2.1.296 ให้อัปเกรดด้วย `claude update` (เหตุผล: Module 4 ใช้คุณสมบัติ debug ตรวจไฟล์ Agent ที่มีตั้งแต่เวอร์ชันนี้เป็นต้นไป)

**ไม่ต้องติดตั้งแอป Claude Desktop** — หลักสูตรนี้ทำงานผ่าน Claude Code ใน Terminal แล็บในชั้นใช้โหมดโต้ตอบ (TUI) บันทึก headless ชุดเก่าอยู่ใน `instructor/test-runs/`

## เจอข่าว "one Claude" แล้วต้องทำอะไรไหม

ไม่ต้องครับ — ข่าวนี้เป็นการรวมโหมดทำงาน agentic (เดิมชื่อ Cowork) เข้ากับ chat **ในแอป Claude** (web/desktop/mobile) ส่วนหลักสูตรนี้ใช้ **Claude Code CLI ล้วน** ซึ่งเป็นผลิตภัณฑ์คนละตัวและไม่กระทบจากการรวมนี้

- หน้าจอแอป Claude อาจแตกต่างกันตามแผนและช่วงเวลา rollout (Pro/Max ได้ก่อน Team/Free ตามมา) — แต่ไม่มีขั้นตอนไหนของคอร์สที่พึ่งหน้าจอแอป
- พอติดตั้ง Claude Code แล้ว login ผ่านเบราว์เซอร์ด้วยบัญชีที่ได้รับ ก็พร้อมเรียนทุก Module

## คำถามที่พบบ่อย

**Q: ต้องสมัคร subscription เองไหม?**
A: ไม่ต้อง — ทางผู้จัดเตรียม Account ให้ระหว่างอบรม (Claude Pro / Team)

**Q: ใช้ Windows ได้ไหม?**
A: ได้ — Windows 10 / 11 ต้องใช้ Git Bash (หรือ WSL) ตามคำสั่งในแล็บ macOS และ Linux ใช้ Terminal ที่มี bash ได้ PowerShell 5.1 ใช้คนละไวยากรณ์กับคำสั่งในแล็บ

**Q: ต้องใช้ editor แบบไหน?**
A: VS Code หรือ Cursor — ใช้เปิดโปรเจกต์และอ่านโค้ด ส่วนการสั่งงานทีม Agent ทำผ่าน Terminal

**Q: ข่าวที่ว่าโหมดทำงานอัตโนมัติถูกรวมเข้า chat เกี่ยวกับเนื้อหาคอร์สไหม?**
A: ไม่เกี่ยวครับ — คอร์สนี้สอนการสร้าง Multi-Agent Systems บน Claude Code ซึ่งยังพัฒนาต่อเนื่องและเป็นเครื่องมือที่ทุก Workshop ใช้จริง
