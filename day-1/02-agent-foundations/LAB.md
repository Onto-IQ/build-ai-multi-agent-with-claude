# Lab — onboard โปรเจกต์ + สาธิต 3 นาที

> ⏱ machine ~5 นาที · Start state: workshop repo clone แล้วจาก Lab 0 · ตรวจเครื่องผ่านจาก Module 1 แล้ว

## Goal / เป้าหมาย

`.claude/` ของโปรเจกต์ถูกตั้งต้นด้วย `/init` และคุณบอกได้หนึ่งไฟล์ที่เสี่ยงที่สุดในแอป พร้อมเหตุผลว่าควรสำรวจต่อแบบขนานหรือต่อคิว

## Steps / ขั้นตอน

1. เปิดเทอร์มินัลแล้วเข้า workshop repo `D:\dev\multi-agent-workshop` — นี่คือครั้งแรกที่คุณแตะ claude (หลังตรวจเครื่องจบแล้ว)

```bash
claude
```

2. พิมพ์ `/init` แล้วกดอนุญาตเมื่อถามเขียนไฟล์ — Claude Code จะสำรวจโค้ดทั้งโปรเจกต์แล้วอัปเดต `CLAUDE.md` ด้วยความเข้าใจของมันเอง

ผลที่คาดหวัง: `CLAUDE.md` มีหัวข้อ "กติกา" เดิมครบทุกข้อ และมีความเข้าใจภาพรวมของแอปเพิ่มเข้ามา (บางรุ่นถาม overwrite/merge — เลือก merge เสมอ)

> 📚 **รู้เพิ่ม:** `/init` คือคำสั่งตั้งต้น `.claude/` ระดับโปรเจกต์ — ทุกเซสชันถัดไปและทุกเอเจนต์ย่อยจะอ่าน `CLAUDE.md` ฉบับที่ปรับแล้วนี้ อ่านสิ่งที่ Claude เขียนจริงด้วยตา: ถ้ามันเข้าใจผิดตรงไหน แก้ไฟล์ด้วยมือได้เลย นี่คือเอกสารของทีม ไม่ใช่ของ Claude คนเดียว

3. วาง prompt ภาษาใดภาษาหนึ่ง (เลือกอย่างหนึ่ง):

**เวอร์ชันอังกฤษ (แนะนำ):**

```text
Explore this project for 2 minutes and name the single riskiest file. Under 80 words.
```

**เวอร์ชันไทย (ใช้ได้เต็มที่):**

```text
สำรวจโปรเจกต์นี้ประมาณ 2 นาที แล้วบอกไฟล์เดียวที่เสี่ยงที่สุด พร้อมเหตุผล ไม่เกิน 80 คำ
```

ผลที่คาดหวัง: คำตอบไม่เกิน 80 คำ และชี้ไฟล์ในโปรเจกต์นี้ เช่น `server.js` หรือ `data/dataset.csv` พร้อมเหตุผลหนึ่งข้อ

4. ถามต่อในเซสชันเดิมหนึ่งประโยค (เลือกอย่างใดอย่างหนึ่ง):

**เวอร์ชันอังกฤษ:**

```text
For the remaining work, should we run it as a swarm or sequentially? Why?
```

**เวอร์ชันไทย:**

```text
งานที่เหลือควรทำแบบ swarm หรือ sequential
```

ผลที่คาดหวัง: การอ่านหลายไฟล์ขนานได้ การแก้ quality gate ต้องรู้ผลของการอ่านก่อน จึงต่อคิว

> 📚 **รู้เพิ่ม:** นี่คือคำถามตัดสินเดียวของทั้งคอร์ส — งานขั้นถัดไปต้องใช้ผลของขั้นก่อนหน้าหรือไม่ ถ้าไม่ต้องแตกขนานได้ ถ้าต้องให้ต่อคิว Module ที่เหลือทั้งหมดใช้คำถามนี้ตัดสิน

## 🛠 Troubleshooting

| อาการ | สาเหตุ | แก้ |
|---|---|---|
| Claude ขอสิทธิ์แล้วเงียบ | ยังไม่กดอนุญาตใน TUI | กดอนุญาตในกล่องของ TUI |
| คำตอบยาวมาก | ไม่ได้ใส่เพดานคำ | ส่งประโยค "under 80 words" ซ้ำ |
| ถูกคิดเงินรายครั้ง | `ANTHROPIC_API_KEY` ทับบัญชีคลาส | ออกจาก TUI แล้ว `unset ANTHROPIC_API_KEY` |
| `claude -p` เขียนหรือรันคำสั่งไม่ได้ | headless ปิด Bash และปฏิเสธ `.claude/**` ได้ | แล็บนี้ใช้ TUI เท่านั้น |
