# Lab — สาธิต 2 นาที

> ⏱ 10 นาที · Start state: `ราก repo` ยังไม่แก้

## Goal / เป้าหมาย

บอกได้หนึ่งไฟล์ที่เสี่ยงที่สุดในแอปเริ่มต้น และบอกได้ว่าไฟล์นั้นควรสำรวจต่อแบบขนานหรือต้องต่อคิว

## Steps / ขั้นตอน

1. เปิด Git Bash แล้วเข้าโฟลเดอร์แอป

```bash
claude
```

2. วาง prompt ภาษาใดภาษาหนึ่ง (เลือกอย่างใดอย่างหนึ่ง):

**เวอร์ชันอังกฤษ (แนะนำ):**

```text
Explore this project for 2 minutes and name the single riskiest file. Under 80 words.
```

**เวอร์ชันไทย (ใช้ได้เต็มที่):**

```text
สำรวจโปรเจกต์นี้ประมาณ 2 นาที แล้วบอกไฟล์เดียวที่เสี่ยงที่สุด พร้อมเหตุผล ไม่เกิน 80 คำ
```

ผลที่คาดหวัง: คำตอบไม่เกิน 80 คำ และชี้ไฟล์ในโปรเจกต์นี้ เช่น `server.js` หรือ `data/sales.csv` พร้อมเหตุผลหนึ่งข้อ

3. ถามต่อในเซสชันเดิมหนึ่งประโยค (เลือกอย่างใดอย่างหนึ่ง):

**เวอร์ชันอังกฤษ:**

```text
For the remaining work, should we run it as a swarm or sequentially? Why?
```

**เวอร์ชันไทย:**

```text
งานที่เหลือควรทำแบบ swarm หรือ sequential
```

ผลที่คาดหวัง: การอ่านหลายไฟล์ขนานได้ การแก้ quality gate ต้องรู้ผลของการอ่านก่อน จึงต่อคิว

> 📚 **รู้เพิ่ม:** นี่คือคำถามตัดสินเดียวของทั้งคอร์ส — งานขั้นถัดไปต้องใช้ผลของขั้นก่อนหน้าหรือไม่ ถ้าไม่ต้องแตกขนานได้ ถ้าต้องให้ต่อคิว Module ที่เหลือทั้งหมดใช้คำถามนี้ตัดสิน

## ✅ Checkpoint

- [ ] เปิด `claude` จาก `ราก repo` ไม่ใช่จากรากดิสก์
- [ ] คำตอบชี้ไฟล์จริงและสั้นกว่า 80 คำ
- [ ] พูดได้ว่าทำไมงานทำความสะอาดข้อมูลไม่ควรขนานกับการออกแบบ

## 🛠 Troubleshooting

| อาการ | สาเหตุ | แก้ |
|---|---|---|
| Claude ขอสิทธิ์แล้วเงียบ | ยังไม่กดอนุญาตใน TUI | กดอนุญาตในกล่องของ TUI |
| คำตอบยาวมาก | ไม่ได้ใส่เพดานคำ | ส่งประโยค "under 80 words" ซ้ำ |
| ถูกคิดเงินรายครั้ง | `ANTHROPIC_API_KEY` ทับบัญชีคลาส | ออกจาก TUI แล้ว `unset ANTHROPIC_API_KEY` |
| `claude -p` เขียนหรือรันคำสั่งไม่ได้ | headless ปิด Bash และปฏิเสธ `.claude/**` ได้ | แล็บนี้ใช้ TUI เท่านั้น |
