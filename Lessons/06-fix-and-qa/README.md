# Module 6 — แก้ crash ด้วย QA handoff / Fix with a QA handoff

เอเจนต์ qa เข้ามาเติมในวงจรที่ Workshop 3 เริ่มไว้: รีโปรดิวส์บั๊กจริง เขียน `docs/QA-REPORT.md` ให้ developer อ่านต่อ แล้วกลับมาตรวจซ้ำหลังแก้ — quality gate ปิดที่ 6/6 ในแล็บนี้

> 📚 ทำไมแยก qa ออกจาก developer: คนที่เขียนโค้ดกับคนที่พิสูจน์ว่าโค้ดพัง ต้องไม่ใช่มือเดียวกัน — รายงานเป็นไฟล์จึงตัดมุก "ผมเทสแล้วเวิร์ก"

<summary>จบแล็บนี้แล้วมีอะไรเปลี่ยนในโปรเจกต์</summary>
