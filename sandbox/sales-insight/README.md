# Sales Insight App

sandbox ของหลักสูตร VIBE-CODE-L2 แอป Node ล้วน ไม่มี dependency

สถานะในโฟลเดอร์นี้คือ **จุดเริ่มต้น** `node scripts/quality-gate.js` ต้องจบด้วย exit code 2

```bash
node server.js
node scripts/quality-gate.js
node mcp/echo-server.js
```

พจนานุกรมคอลัมน์อยู่ที่ `data/README.md` quality gate อยู่ที่ `scripts/quality-gate.js`
