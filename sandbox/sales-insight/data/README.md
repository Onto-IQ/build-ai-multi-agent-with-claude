# sales.csv — พจนานุกรมคอลัมน์

ไฟล์นี้คือก้อนข้อมูลตั้งต้นของ Sales Insight App รวบรวมจากหลายระบบของร้านของฝากสมมติ (สาขา, Shopee, Lazada, LINE) ช่วงมีนาคม 2025 คุณภาพยังไม่พร้อมใช้ — Workshop 4 เป็นคนทำความสะอาด

| คอลัมน์ | ความหมาย | ค่าที่ระบบทำความสะอาดแล้วต้องได้ |
|---|---|---|
| `order_id` | รหัสออเดอร์ ไม่ซ้ำ | `ORD-` ตามด้วยตัวเลข |
| `order_date` | วันที่สั่ง | `YYYY-MM-DD` ปีคริสต์ศักราช และเป็นวันที่จริง |
| `region` | ภาค | ต้องตรงกับจังหวัดในตารางอ้างอิงของแอป |
| `province` | จังหวัด | ชื่อในชุดจังหวัดของไฟล์นี้ |
| `channel` | ช่องทางขาย | `สาขา`, `Shopee`, `Lazada`, `LINE` |
| `product` | สินค้า | ตัดช่องว่างหัวท้ายแล้ว |
| `qty` | จำนวนชิ้น | จำนวนเต็ม ≥ 1 |
| `unit_price_thb` | ราคาต่อชิ้น (บาท) | ตัวเลขธรรมดา ไม่มีจุลภาค ไม่มีสัญลักษณ์สกุลเงิน |
| `discount_pct` | ส่วนลดร้อยละ | 0–100 |

รายได้ต่อแถว = `qty * unit_price_thb * (1 - discount_pct / 100)` ปัดเป็นสตางค์
