# Sales Insight App

โปรเจกต์นี้คือแดชบอร์ดยอดขายของร้านของฝากสมมติ ข้อมูลอยู่ใน `data/sales.csv` เซิร์ฟเวอร์คือ `server.js` (Node `http` ล้วน ห้ามเพิ่ม dependency)

## กติกา

- ตอบเป็นภาษาของผู้ถาม ชื่อไฟล์ ชื่อ endpoint และชื่อฟิลด์คงภาษาอังกฤษ
- งานสำรวจห้ามแก้ไฟล์
- อย่าแนะนำ Express, ฐานข้อมูล หรือแพ็กเกจ npm เว้นแต่จะถูกขอ
- อย่าอ่านหรือคัดลอกค่าที่ขึ้นต้นด้วย `sk-` ออกไปนอกโปรเจกต์
- ก่อนบอกว่าพร้อมส่งมอบ ให้รัน `node scripts/quality-gate.js` แล้วรายงาน exit code จริง
